## What is SF_ExtraTools?

ExtraTools adds utility equipment and machines that extend existing Slimefun progression rather than creating a separate technology tree. This maintained line keeps the original gameplay while modernizing the addon for Minecraft 1.21.11+ and current Paper-family servers.

### Included content

- **Hammer** — pulverizes cobblestone, gravel and dirt into finer materials.
- **Gold Transmuter** — converts between Slimefun gold and vanilla gold.
- **Electric Composters** — powered composting machines.
- **Cobblestone Generator** — passively generates cobblestone while powered.
- **Vaporizer** — produces salt and sulfate materials.
- **Concrete Factory** — converts concrete powder into concrete in batches.
- **Pulverizer** — provides an automation-friendly cobblestone-to-sand path.

## Download and build

Release JARs use the maintained Slimefun-addon naming convention:

`SF_ExtraTools1.2.1.jar`

The repository builds with **Java 25** while targeting **Java 21 bytecode**. The production compatibility baseline is **Slimefun Legacy 4.1.48 on Paper 26.2**. Development builds are available from GitHub Actions and versioned release JARs are published on the Releases page.

---
## Compatibility

Primary target: **Slimefun Legacy**.

Compatibility is also validated against Slimefun United, SlimefunGuguProject/Slimefun4, and original Slimefun4-compatible APIs. Paper is the primary server family; Purpur, Folia and Leaf are compatibility targets. Folia support assumes the installed Slimefun implementation is itself Folia-compatible.

This maintained fork avoids external Slimefun utility-library dependencies. Cross-fork support stays on the shared Slimefun addon API wherever practical.
